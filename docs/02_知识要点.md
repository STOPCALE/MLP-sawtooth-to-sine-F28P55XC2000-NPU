## 1. 任务与核心原理

### 1.1 任务定义（数学化）

取一个周期 $t \in [0, 1)$：

- 锯齿波（网络输入）：$s(t) = 2t - 1$（从 -1 线性升到 +1）
- 正弦波（训练标签）：$y(t) = \sin(2\pi t)$（与锯齿波同周期、同相位）
- 网络学习的映射：**$s \to y$，即 $y = -\sin(\pi s)$**（单值函数）

### 1.2 逐点映射（pointwise waveshaping）

网络是"瞬时值 → 瞬时值"的**静态函数**，与"时间/频率"完全无关：

$$v(t) = g\big(u(t)\big), \qquad g(s) = -\sin(\pi s)$$

- **输入是单点**：当前输出能被当前输入唯一确定 → 单点足够（窗口/特征点/多周期方案仅在"输出无法由单点确定"时才需要）
- **天然频率无关**：频率只决定 $s$ 随时间变化的快慢；$g$ 不感知时间 → 输出自动跟随输入频率
- 实验铁证：freq=1 训练的网络，测 1/3/7.5/20 倍频输入 → **误差恒定 6.1e-3**；100/300/500 Hz 实测 → **误差恒定 5.6e-3**
- ⚠️ 训练时 `FREQ` 语义 = "每周期变换的倍频比"：`FREQ=1` 才是"1:1 同频整形器"（部署用）；`FREQ=k` 是 k 倍频器
- 若任务变为"相位随机"等非单值场景，需升级结构（窗口/参考信号输入）——**结构由任务的信息需求决定**

### 1.3 与"频谱偏置"的关系

本设计从源头避开 spectral bias：学的是固定映射 $-\sin(\pi s)$ 而不是时间函数 $\sin(2\pi f t)$，因此不存在"高频难学/换频率失效"的问题。

## 2. MLP 基础

### 2.1 原理

- 单个神经元：$a = \sigma(w \cdot x + b)$（加权和 + 非线性激活；无非线性则多层退化为线性）
- 网络 = 层的复合；万能逼近定理：足够宽的隐层可逼近任意连续函数
- 训练 = 梯度下降最小化损失；反向传播用链式法则；Adam 自适应步长
- 训练循环六步（所有 PyTorch 训练的心脏）：
  采数据 → 前向 → 算损失 → 清梯度 → 反向传播 → 更新参数

### 2.2 网络规格（部署核算的原始数据）

| 层 | 运算 | 权重形状 | 参数数 | 乘加数 MAC |
|---|---|---|---|---|
| 1 | $h_1 = \mathrm{ReLU}(W_1 s + b_1)$ | 64×1 | 128 | 64 |
| 2 | $h_2 = \mathrm{ReLU}(W_2 h_1 + b_2)$ | 64×64 | 4160 | 4096 |
| 3 | $y = W_3 h_2 + b_3$ | 1×64 | 65 | 64 |
| **合计** | | | **4353** | **4224** |

- 当前版本激活 = **ReLU**（历史版本为 SiLU；两种都能学，ReLU 版量化误差更小）
- 推理阶段：`model.eval()` + `torch.no_grad()`（训练与推理在计算上是两回事）

## 3. 数据集从哪来

**没有数据集文件——"公式本身就是数据集"（合成数据 / on-the-fly 生成）：**

```python
t = torch.rand(n, 1)                  # 现场随机抽时间点
s = 2.0 * t - 1.0                     # 输入
y = torch.sin(2.0 * np.pi * FREQ * t) # 标签
```

- 无限数据思想：数据可解析定义 → 要多少有多少、覆盖连续域、零存储、无"背答案"过拟合
- 何时才需要真实数据集/DataLoader：规律无法用公式描述的任务（图像、语音、真实传感器）

### 4.2 导出要点（`torch.onnx.export`）

## 5. 量化知识（核心）

### 5.1 为什么量化

float32 → int8：体积 4×↓（大模型）、整数算力（NPU 的粮食）、功耗↓。

### 5.2 仿射量化公式

$$q = \mathrm{clamp}\Big(\mathrm{round}\Big(\frac{x}{S}\Big) + Z,\ q_{min},\ q_{max}\Big), \qquad \hat{x} = S\,(q - Z)$$

- 对称量化（$Z=0$）：适用本任务输入/输出（$[-1,1]$，255 级 → $S = 2/255 \approx 0.007843$，与实测 `s_scale` 一致）
- **半格定律**：$|x - \hat{x}| \le S/2$（实测贴脸：W2 误差 2.80e-3 ≤ 上限 2.81e-3）
- **per-channel**（权重）：每个输出通道一把尺子 → 小数值才不吃亏
- 第一步"定尺子"靠**标定（calibration）**：喂一批代表性输入，统计每层激活的 min/max

### 5.3 两个真实发现

1. **W1（64×1）per-channel 完全无损**：每通道仅 1 个数 → 尺子量身定做（这也解释了 0.000162 这类"怪 scale"）
2. **误差不均匀**：同一通道内，尺子被最大数撑开 → 小数值相对误差更大

### 5.4 量化误差预算（PTQ，实测 scale 手算）

输出误差 ≈ 各环节"半格"叠加：输入量化 ±3.9e-3（经斜率放大 ~×3）＋ 第 1 层激活 ±7.6e-3 ＋ SiLU/ReLU 输出 ±3.6e-3 ＋ 第 2 层激活 ±1.4e-2 ＋ 输出量化 ±3.9e-3 ⇒ 最坏 ~3-4e-2，与实测吻合。

## 6. PTQ 与 QAT

### 6.1 PTQ（训练后量化）

流程：标定（`CalibrationDataReader`）→ `quantize_static`（QDQ 格式）→ 验证。

### 6.2 QAT（量化感知训练，"int8 适应训练"）

- **伪量化**：前向时模拟 `round + clamp` 的舍入误差（网络"看到"量化误差）
- **STE（直通估计器）**：`round` 导数处处为 0，无法反传；用一行代码解决：

```python
return x + (y - x).detach()   # 前向 = 量化值; 反向梯度恒为 1 (量化层"透明")
```

- 标准流程：`prepare_qat` → 微调（lr 逐步衰减）→ 冻结观察器 → `convert_fx`
- **两个真实坑**：
  1. 默认 fbgemm qconfig 带 `reduce_range`（7bit 激活）→ 自定义 qconfig 全 8bit（`quant_min=0, quant_max=255`）
  2. 学习率无衰减 → StepLR 衰减到 1e-5

### 6.3 fake-vs-real gap（开放问题）

- fake-quant vs float = **1.77e-3**（网络确实适应了）
- 真 int8 vs float = **3.72e-2**（差 20 倍！）
- 候选原因：算子间 requantize、不同 int8 kernel 舍入、训练未见过的输入/输出量化边界
- **教训：训练时模拟 ≠ 真实推理；验证必须落在最终真实推理链（最终在板端）**

## 7. 部署工程要点

| 主题 | 结论 |
|---|---|
| 输入归一化 | 必须与训练一致（ADC 码值 → [-1,1] 标定）；幅度漂移 = 分布漂移（未标定误差 1e-1 → 标定后 1e-3） |
| 每周期点数 | 决定波形重建质量（50 点/周期平滑；12 点/周期呈多边形） |
| 推理速度 | 4224 MAC + 128 激活/次；500Hz×50点/周期 → 25kHz 更新率（40µs/次预算） |
| 算力参考 | 带 FPU 的 MCU 可行；无 FPU 需定点化/缩网 |
| 模型体积 | float ~18KB / int8 ~10KB（小模型 scale 元数据占比大） |
| 延迟 | 逐点映射无额外延迟（每采样独立计算） |
| 精度代价 | 全 int8 的 max 误差 ~3-4e-2（mean ~7e-3）；不接受则混合精度/更好标定 |

## 9. 手写 int8 推理（PC 端已验证，2026-10-07）

> 完整过程、六个坑与对拍方法见 [05_手写int8推理实战](05_手写int8推理实战.md)。

### 9.1 整数前向公式（带 zero_point 的通用形式）

$$\text{acc}[c]=\sum_j (W_q[c,j]-z_w)(q_{in}[j]-z_{in})+b_{int}[c]$$

$$q_{out}[c]=\mathrm{clamp}\big(\mathrm{round}(\text{acc}[c]\cdot M[c])+z_{out},\ -128,\ 127\big),\qquad M[c]=\frac{S_{in}S_w[c]}{S_{out}}$$

$$\hat x[c]=S_{out}(q_{out}[c]-z_{out})$$

### 9.2 三条关键认识

1. **`b_int` 已吸进整数域**：QDQ ONNX 里 `bias_quantized` 就是 int32，且恒满足 $S_b=S_{in}S_w$（三层逐一验证成立）
2. **ReLU 就是钳位**：隐藏层 $z_{out}=-128$ 代表实数 0 → `clamp` 下界天然实现 ReLU，不需要单独一行 `max(0,x)`
3. **尺子链条**：每层的**输出尺子 = 下一层的输入尺子**（$S_{out}(k)=S_{in}(k+1)$）——串联时唯一要记住的东西

### 9.3 实测数据（`s = 0.5`）

| 步骤 | 值 |
|---|---|
| `q0 = round(0.5 / s_scale)` | 64 |
| 第 1 层 `acc[0]`（int32） | 404681 |
| 第 1 层 `M[0]` | 2.0359e-4 |
| 第 1 层 `q1[0]` / 反量化 | −46 / 0.51248237 |
| 第 3 层 `q3` / 最终 `y` | −126 / **−0.98774355** |
| onnxruntime `y` | −0.98774356（差 1e-8） |
| 批量 1000 点（`q1` 逐位 / `y` max diff） | **0** / 2.98e-8（`batch_bench.py` 复验） |

### 9.4 不用跑代码就能挡错的三条自查

1. **`scale` 与 `M` 恒为正** —— 出现负数 ⇒ 参数传错
2. **饱和指纹**：某个最大值反复出现 ⇒ 被 `clamp` 削平 ⇒ 查 scale
3. **数值自洽推理**：由 $\hat x = S_{out}(q-z_{out})$ 从输出值反推参数（板端无打印时唯一手段）

## 10. 名词速查

| 术语 | 含义 |
|---|---|
| 波形整形（waveshaping） | 用静态函数把输入波形"重塑"成输出波形 |
| 标定（calibration） | 用代表性数据统计激活范围，确定量化 scale |
| QDQ | `QuantizeLinear / DequantizeLinear` 显式量化节点格式 |
| PTQ / QAT | 训练后量化 / 量化感知训练 |
| STE | 直通估计器，让梯度绕过不可导的 round |
| per-channel | 每通道独立 scale（权重）；激活一般 per-tensor |
| 半格定律 | 量化误差 ≤ S/2 |
| MAC | 乘加运算（部署算力的基本单位） |
| 重量化乘子 M | $M=S_{in}S_w/S_{out}$，把 int32 累加器重定标到输出量化域；纯整数硬件上做成定点 $M_0\cdot 2^{-shift}$ |
| 饱和（clamp） | 结果超出 [−128,127] 被削平；"同一最大值反复出现"是它的指纹 |
| int32 累加器 | int8 乘法必须在 int32 里累加，否则溢出 |
