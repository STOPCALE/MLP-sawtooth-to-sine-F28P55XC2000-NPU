## 1. 环境准备

- **Python 环境**：Anaconda 环境 `torch`（路径 `E:\anaconda\envs\torch`）
- 关键包版本：Python 3.10.22 / torch 2.5.1+cu121 / numpy 2.2.6 / matplotlib 3.10.9 / onnx 1.23.2 / onnxruntime-gpu 1.23.2 / Pillow 12.1.1

### ⚠️ 运行方式（重要：不能裸调 python.exe）

该环境的 numpy 是 conda 版（MKL 后端），DLL 在 `envs\torch\Library\bin`，**只有激活环境时才在 DLL 搜索路径里**；不激活直接裸调 `python.exe` 会在 `np.dot`/绘图时原生崩溃（0xC06D007F）。

正确的三种方式（任选）：

```bat
:: 1) 从"开始菜单 → Anaconda Prompt"进入后
conda activate torch

:: 2) 任意命令行里用一行流
conda run --no-capture-output -n torch python 脚本.py

:: 3) cmd 里手动激活
call E:\anaconda\Scripts\activate.bat E:\anaconda\envs\torch
python 脚本.py
```

进入环境后，本目录下直接 `python 脚本.py` 即可（提示符显示 `(torch)`）。

## 4. 修改实验参数（改哪里）

| 想试什么 | 修改位置 |
|---|---|
| 学习高频（spectral bias）实验 | `FREQ`（1.0 → 2.0 / 4.0 / 8.0）——注意：部署用的"1:1 整形器"必须回到 1.0 |
| 换激活函数（量化友好性对比） | `nn.ReLU()` ↔ `nn.SiLU()`（模型定义处） |

## 5. 产物说明（给上板用）

| 文件 | 用途 | 备注 |
|---|---|---|
| `saw2sin.onnx` | 官方工具链第一候选（float） | float 基线，精度 4.6e-3 |
| `saw2sin_int8.onnx` | 工具链对照 / 直接部署 | PTQ QDQ，误差 ~3.1e-2 |
| `saw2sin_qat_int8.onnx` | 参考 | QAT 导出有额外 gap，不如 PTQ 版干净 |
| `saw2sin_qat_state.pt` | **手写推理阶段**读 int8 权重与 scale | 路线 B 的起点 |

**上板建议**：先让官方工具处理 `saw2sin.onnx`（float），记录工具链报告的量化误差；再拿 `saw2sin_int8.onnx` 对照。两个数据对比，判断工具链量化水平。

## 6. 故障排查

| 症状 | 原因 | 处理 |
|---|---|---|
| 裸调 `python.exe` 时 numpy 崩溃（0xC06D007F） | conda numpy 的 MKL DLL 找不到 | 激活环境运行（见第 1 节） |
| `python -c "长代码"` 报奇怪的 SyntaxError | PowerShell 5.1 吞引号 | 改写成脚本文件执行 |
| `set MPLBACKEND=Agg && ...` 报 backend 无效 | cmd 中 `&&` 前的空格进入变量值 | 写成 `set MPLBACKEND=Agg&& ...` |
| `torch.load` 出现 FutureWarning（weights_only） | PyTorch 2.5 提示 | 可忽略；或加 `weights_only=True`（本工程文件为自产，安全） |
| onnxruntime 提示 "consider pre-processing" | 通用建议（面向图像任务） | 本任务可忽略 |
| `figure saved` 后出现 Agg 无法显示图的警告 | 无窗口模式（验证用）运行时正常现象 | 用户本地直接运行时图窗会弹出 |
