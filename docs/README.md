# 锯齿波→正弦波 MLP 学习工程（总览）

> 生成日期：2026-10-06
> 一个"从训练到部署"的完整学习实验：MLP 学习"锯齿波瞬时值 → 正弦波瞬时值"的逐点映射，
> 并完成 ONNX 导出、int8 量化（PTQ）、量化感知训练（QAT），为部署到 F28P55X（TI C2000 + NPU）做准备。

## 一、背景与目标

- **学习者目标**：边缘部署工程师 / 嵌入式（AI/NPU）方向；要求深入"数据与计算"层面的理解
- **本工程使命**：用最小可解释的任务，打通 `训练 → 导出 → 量化 → 上板` 全链路
- **部署目标平台**：F28P55XC2000（TI C2000 实时 MCU，带 NPU，仅作数值与流程参考，不编译其工程环境）
- **两条部署路线**：
  - **路线 A**：PyTorch → ONNX → 开发板官方工具/API 推理（PC 端已完成导出 + PTQ + QAT）
  - **路线 B**：权重提取 → C 头文件 → 量化 → CPU 手写前向推理（下一阶段）

## 五、关键结论速览

1. **任务可解且优雅**：网络学的是"瞬时值→瞬时值"的逐点波形整形函数，天然**与输入频率无关**（100–500 Hz 误差恒定 ~5.6e-3）。
2. **量化第一定律**：量化误差**永远不超过半格**（实测 2.80e-3 ≤ 2.81e-3 上限，贴脸验证）。
3. **ONNX 文件 = 接线图 + 数字表**：整个模型的"知识"就是 4353 个数字（6 张 initializer 表）+ 5 个节点（3×Gemm + 2×Relu）。
4. **QAT 的秘密是一行代码**：`x + (y - x).detach()`（STE，梯度直通），让 round 量化"透明"。
5. **开放问题**：fake-quant（训练模拟）与真 int8 推理存在 gap（1.8e-3 → 3.7e-2），需在真实推理链（最终在板端）上验证。
6. **手写 int8 推理已打通**（2026-10-07）：整数链路 = `int32 累加 → 乘重量化乘子 M → 重定标 → 加 zp → 钳位`，其中 `M = S_in·S_w/S_out`；与 onnxruntime **逐位一致**（中间张量 max diff = 0）。
