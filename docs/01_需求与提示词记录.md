## 四、待办：4 个检验问题（待回答后批改）

1. 模型文件里的"知识"分两部分存，分别是什么？
2. 笔算：权重 $w = +0.0836$，所在通道尺子 $S = 0.001$。它的 int8 格数 $q$ 是多少？反量化回来是多少？误差遵守半格定律吗？
3. 为什么 QAT 能训练？（提示：`round` 的导数是多少？STE 靠什么绕过去？）
4. （加分）ReLU 版实验：PTQ 误差从 4.28e-2 降到 3.14e-2，而 fake-vs-real 的 gap 仍在 3.7e-2。从"尺子/格子"的角度想想：各说明了什么？

<details>
<summary>参考答案（教师版，批改用）—— 建议先自己答完再展开</summary>

1. 结构（节点/接线）+ 参数（initializer 数字表）。
2. $q = \mathrm{round}(0.0836/0.001) = 84$；反量化 $84 \times 0.001 = 0.084$；误差 $4\times10^{-4} \le S/2 = 5\times10^{-4}$，**遵守**。
3. `round` 导数处处为 0（无法反传）；STE 用 `x + (y-x).detach()` 令前向等于量化值、反向梯度恒为 1（让量化层"透明"）。
4. PTQ 改善：ReLU 改变了中间层激活分布，部分"尺子/格子"变细，量化误差源变化；gap 仍在：说明 gap 不是某个激活造成的，主要来自真实推理链的其他环节（算子间 requantize / kernel 舍入 / 输入输出量化等），需在真实链路上验证。
